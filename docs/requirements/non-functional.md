# Requisitos Não Funcionais (RNF)

## RNF1

- O sistema deve **garantir a segurança dos dados dos usuários**, utilizando mecanismos de autenticação e armazenamento seguro das informações.

- Categoria: **Segurança**

## RNF2

- O sistema deve apresentar **tempo de resposta inferior a 3 segundos** para as principais funcionalidades, em condições normais de utilização.

- Categoria: **Desempenho**

## RNF3

- O sistema deve possuir uma **interface responsiva e acessível**, permitindo sua utilização em smartphones, tablets e computadores.

- Categoria: **Usabilidade**

## RNF4

- O sistema deve possuir **disponibilidade mínima de 99% ao mês**, exceto durante períodos programados de manutenção.

- Categoria: **Disponibilidade**

## RNF5

- O sistema deve possuir uma **arquitetura modular e documentação adequada**, facilitando sua manutenção, correção de erros e inclusão de novas funcionalidades.

- Categoria: **Manutenibilidade**

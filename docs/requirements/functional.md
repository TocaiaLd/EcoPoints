# Requisitos Funcionais (RF)

## RF1

- O sistema deve permitir que o **usuário** **crie uma conta** para utilizar o EcoPoints.

- Prioridade: **Alta**

## RF2

- O sistema deve permitir que o **usuário** **visualize um mapa com pontos de coleta seletiva**, contendo sua localização e informações relevantes.

- Prioridade: **Alta**

## RF3

- O sistema deve permitir que o **usuário** **consulte uma tabela de materiais de descarte**, indicando o tipo de lixeira adequado para cada material.

- Prioridade: **Média**

## RF4

- O sistema deve permitir que o **usuário** **cadastre seus descartes**, informando o material descartado e o ponto de coleta utilizado.

- Prioridade: **Alta**

## RF5

- O sistema deve permitir que o **usuário** **acumule pontos de recompensa** a partir dos descartes cadastrados, de acordo com as regras de pontuação estabelecidas.

- Prioridade: **Alta**

## RF6

- O sistema deve permitir que o **usuário** **acesse o endereço de um ponto de coleta por meio de um link clicável**, direcionando-o para seu aplicativo de mapas favorito.

- Prioridade: **Baixa**

## RF7

- O sistema deve permitir que o **administrador** **cadastre e edite pontos de coleta seletiva**, incluindo informações como endereço, localização e materiais aceitos.

- Prioridade: **Alta**

## RF8

- O sistema deve permitir que o **usuário** **acesse conteúdos educativos sobre reciclagem**, apresentados de forma simples e curta.

- Prioridade: **Baixa**

## RF9

- O sistema deve permitir que o **usuário** **consulte sua posição em rankings de reciclagem**, considerando rankings por bairro e por município.

- Prioridade: **Média**

## RF10

- O sistema deve permitir que o **usuário** **reporte irregularidades nos pontos de coleta** e que o **administrador analise e gerencie esses reportes**, podendo atualizar as informações dos pontos.

- Prioridade: **Alta**
